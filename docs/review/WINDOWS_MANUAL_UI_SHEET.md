# Windows 육안·조작 확인 시트 (사람이 30분 안에 훑는 용도)

> **이 시트의 존재 이유**: `WINDOWS_SMOKE_CHECKLIST.md` 의 항목 중 **명령 출력으로 증명할 수 없는 것** — 드래그 동작, 레이아웃, 애니메이션, 색상 전환, Toast 표시, 실제 렌더 — 만 추렸다. 에이전트는 WebView2 창을 보지 못하므로 이 항목들은 **미검증으로 남아 있으며**, 사람이 한 번 눈으로 확인해야 한다.
>
> **자동으로 이미 증명된 항목은 여기 없다.** 그것들은 `WINDOWS_SMOKE_CHECKLIST.md` 에서 `[x]` + 근거 명령으로 체크됐다(§3.0.1 단일파일·로그·토큰부재, §3.0.5 루프백 바인딩·랜덤 포트·무토큰 401, §3.2·§3.5 스캔 블랙리스트·딥링크 `os.startfile` 백엔드 경로). 중복 확인이 필요 없다.
>
> **관련**: P7 루프(`docs/goals/corpbrain-windows-verification-loop.md`), 실행 보고서 `docs/goals/REPORT_P7_windows-verification-loop.md`.

## 0. 준비 (1회)

```powershell
# 빌드 순서 고정 — 바꾸면 안 된다 (vite build 가 dist\ 를 비운다)
npm ci; npm run build
.venv\Scripts\python -m PyInstaller --noconfirm CorpBrain.spec
dist\CorpBrain.exe        # --check-only 없이, 실제 창을 띄운다
```

준비물: 문서 20건+ 폴더 2개(다중 루트), 1-depth 하위 폴더 2개+, `.docx`/`.pdf`/`.txt`/`.md` 각 1건+.

> ⚠️ **먼저 처리할 것 — #149**: 이 시트의 Watcher 항목(§7)은 `POST /watcher/config` 가 기존 DB 에서 `500` 을 내는 결함(#149) 때문에 **현재 재현 불가**다. #149 수정(마이그레이션 `v008`) 후에야 §7 을 확인할 수 있다.

## 1. 셸 기동 · 프레임리스 창 (§3.0.1 / §3.0.3)

| 무엇을 하면 | 무엇이 보여야 하는가 |
|---|---|
| `dist\CorpBrain.exe` 를 더블클릭 | 별도 설치·런타임 폴더 없이 **창 1개**가 뜬다 |
| 작업 관리자를 연다 | `node.exe` 가 **없고**, CorpBrain 프로세스가 **정확히 1개**다(사이드카·다중 프로세스 아님) |
| 창을 크게/작게 리사이즈, 최대화 | 레이아웃이 깨지지 않는다 |
| 창을 1024×640 미만으로 줄여본다 | 그 아래로는 줄어들지 않는다 |
| **기동 직후 첫 페인트를 주시**한다 | **흰 화면이 번쩍이지 않는다.** 번쩍이면 → **#151** 로 이미 등재됨(원인: `create_window` 에 `background_color` 미지정, 기본 `#FFFFFF` vs SPA `bg-slate-950`). 육안으로 재확인해 #151 에 결과를 남긴다 |
| OS 기본 타이틀바를 찾아본다 | **없다.** 앱이 그린 커스텀 타이틀바가 대신 보인다 |
| 타이틀바 빈 영역을 끌어본다 | **창이 이동한다**(`.pywebview-drag-region`) |
| 타이틀바 안의 버튼/배지를 끌어본다 | 창이 **따라 움직이지 않는다**(`.pywebview-no-drag`) |
| 파일 목록/위키 본문을 끌어본다 | 창이 **움직이지 않는다**(`easy_drag=False`) |
| 본문 텍스트를 마우스로 드래그 선택 | **선택된다**(`text_select=True`) |

## 2. WebView2 Runtime 부재 분기 (§3.0.2)

> 이 PC 에는 WebView2 Runtime 이 설치돼 있어(`pv=151.0.4129.72`) **부재 다이얼로그를 여기서 실증할 수 없다.** 런타임이 없는 별도 PC(또는 런타임 제거 후)에서만 확인 가능.

| 무엇을 하면 | 무엇이 보여야 하는가 |
|---|---|
| WebView2 **미설치** PC 에서 exe 실행 | 안내 다이얼로그가 뜬다 |
| 다이얼로그 문구를 읽는다 | Evergreen Bootstrapper **주소가 문자열로** 보인다 |
| 네트워크를 감시(Fiddler 등) | 앱이 부트스트래퍼를 **자동으로 내려받지 않는다**(DEC-15) |
| 다이얼로그의 확인을 누른다 | **크래시 없이** 종료(오류 보고 대화상자·트레이스백 창 없음) |
| 런타임 설치 후 재실행 | 정상 기동한다 |
| **per-user(HKCU)만** 설치된 PC 에서 실행 | "런타임 없음" 으로 **오탐하지 않는다**(탐지는 HKLM\WOW6432Node·HKLM·HKCU 세 위치) |

## 4. 워크스페이스 · 스캔 · 대시보드 (§3.1 / §3.2 / §3.3)

| 무엇을 하면 | 무엇이 보여야 하는가 |
|---|---|
| 폴더 2개를 골라 워크스페이스 생성 | 사이드바에 즉시 나타난다 |
| 같은 폴더를 두 번 선택 | 1개로 합쳐진다(#66) |
| 없는 경로를 입력 | **Toast** 로 거부, 워크스페이스 안 생김 |
| 앱을 완전히 종료 후 재실행 | 워크스페이스·폴더 목록이 그대로(#66) |
| 스캔 실행 | 프로그레스 바가 `N/M`·퍼센트로 갱신 |
| 스캔 완료 | **Toast**(전체화면 모달 아님), 이후 폴링이 멈춘다(Network 에 1초 요청 안 쌓임) |
| 10,000개 초과 폴더 스캔 | 절단 경고 Toast, 마지막 Toast 가 "완료" 라고만 하지 않음(#64); 대시보드 캡션이 **주황색** "10,000개 제한 도달" |
| 폴더를 좁혀 재스캔 | 캡션이 다시 **초록색** 으로(#64 회귀 검출) |
| 대시보드 통계 | '총 스캔 문서' 가 실제 수와 일치(0/빈값 아님), '핵심 중요 문서(50점+)' 가 분석 후 0 아님 |
