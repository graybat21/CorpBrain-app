## :gear: Technical & Non-Functional Constraints
- 일관성: 모든 JSON 필드명은 **`snake_case`** 로 통일한다 (`DEC-03`). camelCase 변환 계층(Pydantic `alias_generator`)을 도입하지 않는다.
- 일관성: 모든 응답은 성공 `{ok: true, data}` / 실패 `{ok: false, error}` 봉투를 따른다.
